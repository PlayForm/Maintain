## 0.2.5

### Fix

- Fixed circular dependency in `Source/Fetch.sh`: `ExtractVersion()` and
  `ExtractTag()` previously grepped both `./Workflow/` and
  `./.github/workflows/`. Because `.github/workflows/*.yml` are generated by
  `Maintain Workflow`, reading them back caused a feedback loop — if the
  generation env var was `undefined`, the `# undefined` got baked into the
  generated file and then read back as the "source of truth". Now both functions
  read exclusively from `./Workflow/`, which is the actual template source.
